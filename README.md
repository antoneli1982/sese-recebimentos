# SESÉ Recebimentos

SaaS operacional para controle do recebimento de veículos, filas, divergências e indicadores.

## Funcionalidades

- Cadastro de recebimentos com validação de campos obrigatórios
- Prevenção de nota fiscal duplicada por fornecedor
- Fluxo Gate → encaminhamento → almoxarifado → conclusão
- Fila operacional priorizada por tempo e divergência
- Dashboard de desempenho e meta de 60 minutos
- Importação e exportação em Excel (.xlsx)
- Filtros por gate, chapa SESÉ, fornecedor, transportadora, placa, turno e origem
- Banco de dados persistente
